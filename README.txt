IPRAC — CONCEPT DIGITAL 2026

PRIMA DI TUTTO
Sito statico multipagina pensato per GitHub Pages, senza build e senza framework.
Contiene 23 pagine HTML con nomi univoci nella cartella principale, piu' assets/.

PUBBLICAZIONE
1. Aprire in GitHub Desktop il repository IPRAC-anteprima.
2. Aprire Show in Explorer. Sostituire i vecchi file del sito con TUTTO il contenuto di questa cartella, compresa assets/. Non eliminare .git.
3. Tornare in GitHub Desktop, inserire Summary, cliccare Commit to main e Push origin.
4. Se GitHub Pages e' gia' configurato main / (root), il link esistente si aggiorna.
5. Verificare URL /index.html, /progetti.html e /selezione-foto.html, inclusi mobile e navigazione.

FOTOGRAFIE
Sono stati lasciati spazi chiaramente identificati. Non sono usate fotografie di fantasia.
Aprire selezione-foto.html per consultare gli slot e inserire nomi di file e note.
Usare SCARICA SCELTE / JSON per condividere col titolare le decisioni.
Nessuna fotografia viene salvata online automaticamente: occorre integrare i file successivamente.
Mappatura strutturata in assets/slots.json.
