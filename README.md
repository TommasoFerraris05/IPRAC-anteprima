# IPRAC — concept web navigabile

## Visualizzare

Aprire `index.html` in un browser, oppure avviare un server statico dalla cartella del progetto: `python3 -m http.server 8000` e visitare `http://localhost:8000`. Le pagine sono file HTML con URL separati.

## Contenuti e limiti

Questo è un prototipo di design, non il sito ufficiale IPRAC. Il brief nomina otto progetti e sei competenze, ma le immagini, il logo ufficiale, il testo tecnico verificato e i dati di contatto non sono stati recuperabili dall'ambiente. La firma tipografica usata NON è il logo ufficiale. Nessuna illustrazione tecnica rappresenta un progetto realmente eseguito. Il form è solo dimostrativo e non invia messaggi. Pagine legali da approvare. Filtri realmente funzionanti, tutte le 8 schede attualmente classificabili come da documentare.

## Pubblicazione

Caricare la cartella su un host statico (Netlify, Cloudflare Pages, Apache o Nginx) mantenendo la struttura delle directory. Configurare una pagina 404 dedicata se supportata dall'host. Prima di pubblicare ufficialmente, sostituire la firma con il logo ufficiale con permesso, integrare fotografie originali autorizzate, approvare copy e dati e connettere un servizio backend per il form.
